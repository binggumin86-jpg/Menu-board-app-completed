# 브릿지 커피 디지털 메뉴판

손님이 테이블의 QR코드를 찍으면 휴대폰으로 보게 되는 카페 메뉴판입니다.
`index.html` 파일 하나로 만들어져 있어서, 따로 설치할 것 없이 브라우저로 열면 바로 보입니다.

## 주요 기능

- **카테고리 버튼**: 전체 / 커피 / 논커피 / 디저트. 누르면 해당 메뉴만 보입니다.
- **사장님 추천 배지**: 지정한 메뉴에 배지를 달고 카드를 더 돋보이게 합니다.
- **오늘 품절 표시**: 품절 메뉴는 흐리게 보이고 "오늘 품절"이 뜹니다.
- **전화 걸기 버튼**: 누르면 가게로 바로 전화가 걸립니다.
- **글래스모피즘 디자인**: 반투명 카드, 부드러운 그림자, 둥근 모서리. 휴대폰 화면(폭 390px)에 맞춰져 있습니다.

## 사용 방법

1. `index.html` 파일을 브라우저로 엽니다.
2. QR코드로 쓰려면 이 페이지를 인터넷에 올린 뒤, 그 주소를 QR코드로 만들어 테이블에 붙입니다.
3. QR코드는 `qr.html`을 브라우저로 열어서 만듭니다. 주소를 입력하고 "QR 만들기"를 누른 뒤, 이미지로 저장하거나 바로 인쇄하면 됩니다.

## 메뉴 고치는 방법

메뉴 정보는 `index.html` 맨 위 한곳에 모여 있고, 한국어 설명이 자세히 달려 있습니다.

- **가격 바꾸기**: 메뉴 줄의 `가격: "4,500원"` 안의 숫자만 바꿉니다.
- **메뉴 추가하기**: 메뉴 한 줄을 복사해 아래에 붙이고 이름, 가격, 설명을 바꿉니다.
- **품절 켜고 끄기**: `품절: "X"`를 `품절: "O"`로 바꾸면 켜지고, 되돌리면 꺼집니다.
- **추천 배지 켜고 끄기**: `추천: "X"`를 `추천: "O"`로 바꾸면 붙습니다.
- **전화번호 바꾸기**: `tel:` 뒤의 번호를 실제 번호로 바꿉니다.

고친 뒤에는 브라우저에서 새로고침(F5)해서 확인하세요.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 메뉴판 전체(화면, 디자인, 메뉴 정보) |
| `qr.html` | 인터넷 주소를 QR 코드로 만들어 주는 페이지(이미지 저장·인쇄 가능, 인터넷 없이도 작동) |
| `CLAUDE.md` | 이 프로젝트를 만들 때 지키는 규칙 |
| `자료/` | 가게 정보를 적은 기획 시트 |
